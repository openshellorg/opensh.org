= Site diagrams

Committed Themed SVG figures synchronized to opensh.org.

* **Authority:** https://github.com/dev-centr/scriptbook/tree/97534371f0da8d81e495cb4cc069704902dbdd69[`dev-centr/scriptbook` commit `9753437`] owns the twelve PlayTime sources and artifacts. https://github.com/openshellorg/shell-architecture[`openshellorg/shell-architecture`] owns the four OpenShell-native diagrams.
* **Sync:** `pnpm playtime:sync` reads the pinned commit from a local Scriptbook checkout (`PLAYTIME_SOURCE` overrides discovery). `pnpm diagrams` also synchronizes the four OpenShell-native pairs from `DIAGRAM_SRC` or a neighboring shell-architecture checkout.
* **Validation:** `pnpm test` checks pinned checksums, XML, safety, accessibility, adaptive light/dark presets, host output, progressive markup, same-origin URLs, runtime 0.1.1, manual theme tokens, and the generated news pages.
* **Delivery:** ordinary adaptive images work without JavaScript. `@dev-centr/themed-svg` 0.1.1 progressively replaces marked images with sanitized host artifacts so the manual `data-theme` palette applies.
* **Pages:** CI deploys committed assets and validates them without regenerating PlayTime or depending on a Scriptbook sibling checkout.

All twelve prior hand-authored PlayTime illustrations remain fixed under `assets/illustrations/`.
