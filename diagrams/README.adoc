= Site diagrams

Committed Themed SVG figures synchronized to opensh.org.

* **Authority:** https://github.com/openshellorg/shell-architecture[`openshellorg/shell-architecture`] owns `.mmd`, manifest, adaptive `.svg`, and `.host.svg` artifacts.
* **Sync:** `pnpm diagrams` copies both committed artifacts from a sibling checkout (or `DIAGRAM_SRC`); `pnpm diagrams -- --check` reports drift.
* **Delivery:** ordinary adaptive images work without JavaScript. `@dev-centr/themed-svg` 0.1.1 progressively replaces marked images with sanitized host artifacts so the manual `data-theme` palette applies.
* **Pages:** CI may deploy committed assets without downloading a browser; canonical CI performs regeneration/freshness checks.

The four PlayTime illustrations classified as non-diagrams remain under `assets/illustrations/` unchanged.
