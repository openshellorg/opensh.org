= PlayTime as a shell-boundary cousin
:revdate: 2026-08-13
:description: A document runner that spawns argv without a shell rhymes with OpenShellOrg. It is being built in Dev-Centr scriptbook. We are not moving it.

Dev-Centr is teaching a document to *play*.

Not tangle source (that is their literate-programming track). Play: install this, check that, on *this* computer, without rewriting the file. The engine in the middle picked up a name from the phrase "at play time" -- **PlayTime**.

That engine does something we already preach. It treats an install method as **argv**, not as a bash costume and a pwsh costume and a nu costume hanging on the same hook. It snapshots the host *before* it asks a catalog anything, because "what OS am I?" cannot be an equivalence lookup that requires knowing the OS.

That is shell-boundary work. Entrypoint Dispatch, SOS, structured pipelines -- different layers, same allergy to lying about what process you just started.
