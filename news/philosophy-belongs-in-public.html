Philosophy belongs in public

Dev-Centr alignment, the NVIDIA name collision, and keeping the GitHub profile README for visitors.

Some notes are useful and easy to put in the wrong place.

Profile vs docs

The GitHub org profile README is for people who just arrived. It should say what we are and where to start — not host internal alignment memos.

So we moved the longer write-up into the docs:

Philosophy

That page covers:

  • The two tracks (SOS + structured shells)

  • How OpenShellOrg relates to Dev-Centr (recommend/configure vs standardize/tool)

  • The NVIDIA OpenShell name collision

A small ops lesson

The org profile only renders when openshellorg/.github is public. Private special repos hide the profile README entirely — even when profile/README.md is perfect.
