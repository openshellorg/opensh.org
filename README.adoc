== Usage

=== News / blog

Author posts as AsciiDoc in `news/posts/`:

[source]
----
news/posts/YYYY-MM-DD-slug.adoc
----

Required attributes:

* Document title (`= Title`)
* `:revdate: YYYY-MM-DD`
* `:description:` — short summary for the feed

This writes `news/index.html`, one HTML page per post, and `news/feed.xml` (RSS).

CI runs the same build before deploying GitHub Pages.
