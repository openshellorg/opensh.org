OpenShellOrg

Better shells. Better CLIs. Less friction.

We write shared rules for command-line tools, certify tools that follow them, and ship small helpers around better shells — especially Nushell. We do not invent another shell language.

Not NVIDIA OpenShell (agent sandbox runtime).

Three bets

  • Flags you can learn once SOS (“Save Our Syntax”) is a shared spelling for common options, plus a mark for tools that keep that promise.
  • Pipes that carry real data Classic shells jam “data for the next command” and “layout for your eyes” into the same stream. Structured shells pass tables between commands and only format what you see at the end. We endorse Nushell as the Unix-centric reference — we document the model and ship helpers; we do not reinvent it.
  • Honesty when you hit Enter If a project asks for a specific toolchain, the process that starts should be that one — or the tool should install what’s needed and restart this command, without rewriting the machine default. Entrypoint Dispatch

A sibling workshop, not a merger
